# Jodnoi (จดหน่อย)

แอปบัญชีรายรับรายจ่ายส่วนตัว ใช้ง่าย บันทึกได้ใน 3 แตะ เตือนให้มีวินัยในการจด ("จดหน่อย")
ติดตั้งลงหน้าจอโฮมได้แบบ PWA ใช้ออฟไลน์ได้ ข้อมูลเก็บในเครื่อง (IndexedDB) ไม่ต้องสมัครสมาชิก

## ฟีเจอร์
- บันทึกเงินเข้า/เงินออก พร้อมหมวดหมู่ที่กำหนดเองได้ (ชื่อ ไอคอน สี)
- หลายบัญชี เลือกดูทีละบัญชี (บัญชีเริ่มต้น + เพิ่มเองได้) หมวดหมู่ใช้ร่วมกัน
- ประวัติจัดกลุ่มตามวัน แก้ไข/ลบ พร้อมเลิกทำ
- แดชบอร์ดสรุป ค่าเริ่มต้นเป็นเดือนปัจจุบัน เลือกช่วงวันที่เองได้
- สำรอง/นำเข้า JSON และส่งออก CSV
- ปุ่มติดตั้งแอป (PWA)

## Tech
React 19 · Vite · TypeScript (strict) · Tailwind v4 · Dexie (IndexedDB) · Recharts · vite-plugin-pwa · Vitest

## รันบนเครื่อง
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests
npm run build    # production build (dist/)
```

## ข้อควรรู้
- ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องเท่านั้น หากล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องข้อมูลจะหาย ควรสำรอง JSON เป็นระยะ
- การติดตั้ง PWA และโหมดออฟไลน์ต้องเปิดผ่าน HTTPS (หรือ localhost)
